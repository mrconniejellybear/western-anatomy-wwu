# Western Anatomy

**[westernanatomy.com](https://westernanatomy.com/)** — an interactive 3D brain model for learning human neuroanatomy, built for neuroscience and psychology students by Connor Mausolf at Western Washington University.

WesternAnatomy (placeholder name) runs entirely in the browser. Rotate the brain, isolate a single structure, or pull the whole model apart, then click any region to read what it is, where it sits, and what it does. No installs, no plugins, no account.

## Features

- **Interactive 3D model** built with Three.js — rotate, zoom, isolate individual structures, and explode the model into its parts
- **100+ structure entries** covering gyri, sulci, the lobes, subcortical and limbic structures, the brainstem, and the ventricular system
- **Info panel for each structure** with its function, location, and connections, plus color-coded function tags (emotion, motor, memory, sensory, and more)
- **Two ways to browse** — structures grouped by system, or one alphabetical list, with search and function filters
- **Preset viewing angles** from a dropdown, so you can snap to standard anatomical views
- **Works on mobile** with a touch-first navigation mode
- **Fully sourced** — every entry is backed by the [Sources & References](https://westernanatomy.com/references) page (Kenhub, Radiopaedia, published literature, lab dissections, and textbooks)

## Languages

- [Three.js](https://threejs.org/) (OBJLoader, MTLLoader, OrbitControls)
- Vanilla HTML, CSS, and JavaScript — no framework, no build step

The brain surface is based on Destrieux-atlas cortical parcellation meshes, with subcortical structures modeled and organized in Blender.

## Information/Desc. Sourcing

A complete list of 148 sources is available on the sources page of the website, here: https://westernanatomy.com/references 

For brevity's sake, the outlets and publications used in the creation of westernanatomy.com were: Kenhub, PubMed, Cleveland Clinic, Radiopaedia, Britannica, the University of Utah, the University of Southern California, Duke University Medical School, and a few miscellaneous sources. If not from the aforementioned publications, information came from a legitimate medical journal or a similarly credible .org/.edu, as listed below. 

Because the brain is the most complex, intricate organ in the human body, a quality library must be built from credible information. For this reason, any websites using AI-generated/summarized data were excluded to avoid inaccuracies.
