# Western Anatomy

**[westernanatomy.com](https://westernanatomy.com/)** — an interactive 3D brain model for learning human neuroanatomy, built for neuroscience and psychology students.

Created by [Connor Mausolf](https://www.linkedin.com/in/connormaus/) at Western Washington University.

## About

Western Anatomy lets students explore a fully interactive 3D model of the human brain in the browser — rotate, isolate, and click into individual gyri, sulci, and subcortical structures to pull up detailed, structured descriptions of each region's location, function, and connections. No installs, no plugins, just a browser.

## Features

- Interactive 3D brain model (Three.js + OrbitControls) — rotate, zoom, and isolate structures
- 90+ detailed entries covering gyri, sulci, subcortical structures, the brainstem, and the ventricular system
- Filter by lobe/system or by cognitive, motor, or sensory function
- Full-text search and a synced sidebar index
- Mobile-friendly, with a dedicated touch-first navigation mode
- [Sources & references](https://westernanatomy.com/references) cited for every entry

## Built With

- [Three.js](https://threejs.org/) (OBJLoader, MTLLoader, OrbitControls)
- Vanilla HTML, CSS, and JavaScript — no framework, no build step
